# Sources

The scoring contract is adapted from this project's original direction scorer. The packaged scripts use Python's standard library.

The workflow draws on focused clarification and agent-facing writing guidance from [Matt Pocock's skills](https://github.com/mattpocock/skills/tree/5ae481693d13b37d4d2c2c92d0b66d299c93e695) and the product validation approach in [startup-skill](https://github.com/ferdinandobons/startup-skill/tree/a5f97c317b93caedbb49d28f20e9ec283b2ec087). This package describes these methods in its own words and bundles its own templates and scripts.

Other process references are linked in [the delivery guide](idea-triage/references/delivery-flow.md).

The evidence-to-action check adapts the adverse-evidence review and build threshold in [Product Factory OS — Discover](https://github.com/hihol-labs/product-factory-os/blob/12085574c27f20c24d12937569e928ea706f309f/skills/discover/SKILL.md) (MIT). The check for prior behavior also draws on the customer-discovery gate in the Startup Skill version linked above. This package uses its own wording and existing state model.

The readiness and handoff checks draw on [LANYANT Skills — Idea Assessment](https://github.com/ericwang200608-beep/LANYANT-Skills/blob/22e3f892911a65a42269ec4d19e586cb1b59a559/idea-assessment/references/decide.md). The upstream skill directory includes an MIT license. This package independently describes the checks and keeps its own verdicts and review history.

The decision-changing test draws on [Product Idea Stress Test](https://x.ai/bot/marketplace/bots/product-idea-stress-test), a public Grok Bot template by Hiten Shah, and on the evidence-grounded argument review in [DIALECTIC](https://github.com/pantageepapa/DIALECTIC/tree/dfb296ca5cb69054a289e34531df9782aa2cf4c8) (MIT). This package describes the methods in its own words and uses a short, optional review of competing explanations.
